# マブラヴ ガールズガーデン Mellow Days (마브러브 걸즈가든 Mellow Days) 한국어 패치

![한국어 패치 적용 타이틀 화면](images/title.jpg)

Steam 작업 동반 어드벤처 **マブラヴ ガールズガーデン Mellow Days** (MUV-LUV GIRLS GARDEN Mellow Days) 체험판의 비공식 한국어 패치입니다.

## 설치

1. [Releases](../../releases)에서 `MuvLuvGirlsGardenMellowDaysDemo_KoreanPatch_v*.zip`을 받습니다.
2. 압축 안의 `garden_Data` 폴더를 게임 폴더(`garden.exe`가 있는 폴더)에 덮어씁니다.

패치 전에 게임을 실행한 적이 있다면 설정(⚙) → 全般 → 言語에서 「한국어」를 고릅니다.

## 면책

팬 번역이며 개발사·배급사와 관계가 없습니다. 게임의 권리는 각 권리자에게 있습니다.
